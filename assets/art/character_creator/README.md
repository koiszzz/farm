# 可选人物基座 v1

玩家人物由独立图层合成，而非从成套完整角色中挑选。这样肤色、五官、头发和服饰
可以任意组合，并且每一种组合都使用同一份行走和交互动画。

## 当前源资源

| 文件 | 内容 | 运行时处理 |
| --- | --- | --- |
| `body_base_3x4_source_v1.png` | 无五官、无头发的中性身体动作基座 | 裁为 3×4、12 帧；肤色通过色板替换 |
| `hair_options_source_v1.png` | 8 种头发造型 | 裁为独立透明叠层，按所选发色替换调色板 |
| `face_feature_options_source_v1.png` | 眼睛、鼻子、嘴巴、耳朵选项 | 按五官锚点裁切，并分别叠加 |
| `basic_clothes_source_v1.png` | 8 套基础服饰 | 裁为服装叠层；后续为每套补齐 3×4 动作帧 |

源图不得直接作为游戏贴图。正式资源会导出到 `characters/customization/`，每一层必须
有相同的 3×4 帧格与透明背景。

## 选项范围

- 肤色：8 种色板，作用于身体、耳朵和露出的四肢。
- 头发：8 种发型 × 8 种发色。
- 眼睛：8 种造型 × 6 种眼睛颜色。
- 鼻子：4 种；嘴巴：4 种；耳朵：8 种。
- 基础服饰：8 套。服饰不锁定人物性别，所有组合均可选。

## 动作与锚点规则

人物的每个可见层都必须遵守 [`../ANIMATION_CONTRACT.md`](../ANIMATION_CONTRACT.md)：
3 行（下、左、右）× 4 列（待机、行走 A、行走 B、使用）。不能只给某个发型或服饰
补静态正面图，否则该选项不能进入游戏。

层级由后至前为：身体 → 耳朵 → 服饰 → 眼睛 → 鼻子 → 嘴巴 → 头发。创建界面使用
96×144 的放大头像以展示细小五官；进入地图后渲染相同选择的 32×48 组合精灵。

完整字段与默认值见 `character_creator_v1.json`。存档只记录这些选择 ID，不保存拼合后
的图片，因此扩展发型或服装不会破坏已有角色。
