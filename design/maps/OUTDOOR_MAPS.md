# 户外地图与人物行动区

视觉概念图只用于风格和布局。运行时地形、碰撞、人物路线和交互点必须读取
`outdoor_navigation_v1.json`；它是唯一的导航真相。

## 标记图例

| 标记 | 含义 | 人物移动 |
| --- | --- | --- |
| 绿色 | 草地 | 可移动 |
| 金色 | 路径、桥 | 可移动 |
| 棕色虚线 | 可耕种土地 | 空地可移动；有作物时不可移动 |
| 红色 | 建筑、围栏、石头等实体 | 不可移动 |
| 蓝色 | 水面 | 不可移动 |
| 紫色 | 交互站位格 | 可移动，按键触发交互 |
| 粉色 | 场景出口 | 可移动，越界切换场景 |

## 强制实施规则

1. Godot `TileMapLayer` 的碰撞层从 `solid` 和 `water` 区生成，不能另行手绘一套。
2. 每个建筑门、箱子和公告牌的可交互格使用 JSON 的 `interaction` 坐标。
3. NPC 巡逻路线节点必须在 `path` 或 `grass` 的可行走格内；加载地图时验证。
4. 作物生长后，在对应 `tillable` 格叠加 `crop_occupied` 碰撞；收获后立即移除。
5. 地图显示的标注、碰撞和实际移动必须在同一坐标系（32px 一格）中读取该数据。

当前版包括：40×30 的农场户外地图，以及 48×32 的城镇广场地图。农场西侧与
城镇东侧出口互相连接；所有入口与到达坐标已写入地图数据。
