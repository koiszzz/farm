# 居民关系事件选择

好感达到 200 / 500 后，与居民交谈会打开一段个人关系事件。对白展示场景叙述和居民肖像，玩家可以选择两种回应之一，获得不同奖励；也可以暂时推迟，稍后重开同一事件。只有完成选择才会写入事件里程碑和奖励，避免打开面板就自动领奖。

截图由 Godot 4.7.1、Windows D3D12、NVIDIA RTX 3050 运行 `friendship_event_test.gd` 时采集：

- `florist-choice.png`：小芙的回应选择画面。
- `florist-reward.png`：选择另一分支后显示的回应与奖励。

验证：headless 171 项、真实窗口 174 项，均 0 失败；居民日程 212 项、生活系统 95 项也通过。截图没有游戏世界地名或人物头顶文字。
