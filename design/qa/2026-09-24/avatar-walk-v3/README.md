# 主角行走图集 v3 实机检查

- 资产：`assets/art/runtime_generated/farmer_walk_v3.png`
- 使用位置：`AvatarRenderer`，8帧×4方向；按实际位移选帧
- 实机：Windows，Godot 4.7.1，OpenGL Compatibility，RTX 3050，1280×1040
- `live-cycle.png` / `live-run-cycle.png`：四方向全部32帧在实际角色渲染器中的步行/跑步列阵；现按固定窗口尺寸捕获
- `frame-analysis.json`：逐格边界、可见范围、脚点Y与帧相似度

## 观察

旧素材的上方向脚底高度跨度为16像素，新图集四方向均为0或1像素。下、上方向的最高帧相似度有所下降；左、右方向仍有近似姿势。输出尺寸1774×887不整除8×4，当前切帧宽高会有1像素差，尚需修订图集尺寸及动作关键姿势。

`movement_input_test.gd`和`game_smoke_test.gd`均通过。它们验证输入和基础启动，不代表整个游戏的实时步态已经完成用户试玩验收。

当前把游戏实际使用的 `walk/run` 动作接入可选头发摆动；主角身体步行起伏为1.0世界像素、跑步为2.5，步行落脚帧和阴影锚点保持原位。运动输入回归覆盖停止、反向、等速斜走和两种起伏幅度。48格真实渲染跨区路线最新P95/P99为12.15/14.19ms；唯一超过25ms的帧为路线启动首帧35.9ms，没有持续性地形边界尖峰。详细帧样本见 `../../2026-09-21/free-movement/latest.json`。

正面/背面步姿仍比侧身不明显；`avatar-walk-v4-candidate` 的网格审查结果见相邻目录，没有替换该运行时资产。
