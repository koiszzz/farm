# 主角步态图集 v5

v5 将运行图集从 v4 候选中选出。仍为 1536×1024 的8×4四向循环，保留现有角色造型和距离驱动选帧方式；较大的前后脚分离及摆臂差异用于改善“角色在滑动”的观感。当前正式图集为 `assets/art/runtime_generated/farmer_walk_v5.png`，旧版 v4 仍保留可快速回退。

逐帧比较中，v5每行最相似帧的相似度为：下0.8890、左0.9023、右0.9004、上0.8901；v4对应为0.9336、0.9462、0.9196、0.9640。相似度越低表示姿势区别越大，但这只是图像指标，不替代实际游玩观感。

资源的底部脚像素贴近部分帧格下沿：水平边界计数451个不透明像素，垂直边界为0。Godot运行时对 `Sprite2D` 启用 `region_filter_clip_enabled` 和最近邻采样；D3D12实机四向列阵截图未观察到跨行串帧，脚底仍锚定在固定影子上。`avatar_rendering_test.gd`现有35项，包含资源选择、裁切配置及32帧可见高度；移动输入、动作系统回归也通过。

画面证据：`live-cycle.png`、`live-run-cycle.png`。限制：还没完成真实玩家长时间试玩；部分图格行边缘缺少安全空白，后续重新绘制或导出素材时应优先恢复透明边距，并保留切片裁切保护。
