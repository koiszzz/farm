# 背包页面布局复核

针对旅行手册背包在 1280×720 窗口中的排版做了实机修订：七列物品格配固定详情栏，悬停或键盘选择只更新详情栏，说明不再浮在格子上方。完整说明由 I 展开/收起，Esc 先收起说明，再退出背包；快捷栏仍为十格。

- `backpack-grid.png`：D3D12 窗口实机画面，25格、十格快捷栏与详情栏同屏。
- `backpack-goods.png`：滚动到背包下部的 D3D12 实机画面，显示果树苗、果实、料理、畜产品、加工品和农场设施新图标。
- `item-details.png`：选中物品后展开说明，侧栏展示对应物品图标、数量、分类和用途。
- `inventory_visual_test.gd`：183项通过，检查26格新图集映射、各类别实际背包缩略图、统一格子尺寸、详情栏不覆盖格子、悬停切换与说明展开。
- `inventory_input_test.gd`：11项通过，使用真实键盘事件检查 I/Esc、七列上下移动、快捷栏物品使用与食用。

本轮参考《星露谷物语》[官方媒体截图页](https://www.stardewvalley.net/media/)和[官方新闻资料页](https://www.stardewvalley.net/press/)观察其温暖、清晰的像素物件表达；所有新增图标为项目原创，没有导入原作截图或贴图。周边场景参考页另有农场/海岸/镇区/郊外/洞穴实机截图；地图地面不绘制地点文字，人物头顶也没有姓名或提示标签，互动信息通过实体路标和固定HUD阅读。

实机环境：Godot 4.7.1、Windows、D3D12、NVIDIA RTX 3050。此轮只完成背包一页的密度和详情可读性修订，角色卡滚动、地图可读性、设置音量持久化/听感和其它物品分类页仍需继续完善。
