### 2026-09-25：联网补看场景参考并修正沙滩入口构图

对照官方媒体/截图入口和区域资料，把“先看到海岸边界与区域地标，再自然发现该区活动”的组织方式用于花溪五区；农场、城镇、海滩、郊外和矿洞分别保留自己的地貌及玩法组合。沙滩资料强调海岸拾取、垂钓和开放岸线，因此入口第一屏应能同时辨认渔屋、潮池、栈道与岸边活动点。参考地图只用于构图和区域功能，不复制原作地图或美术素材。

对照海滩入口实机图发现旧落点靠地图上沿，且额外镜头偏移让人物与渔屋分离。现在入口和新档出生点放到北岸与栈道的连接处，并取消海滩专用镜头偏移；碰撞、采集刷新位置、路线和其他地图镜头都不变。更新后的窗口截图为 `beach-entry.png`，能同时看到渔屋、潮池、栈道和拾贝点。`regional_world_test.gd` 在 Windows / Godot 4.7.1 / NVIDIA RTX 3050 D3D12 下 334 项检查、0 失败，包含五区行走、互动数据、海滩镜头与场景动画生命周期。

本次只把地点构图和活动组合用于分析：海岸与沙地要有清楚交界，钓鱼设施、潮池、漂流物与休憩点需要分布在可探索路线附近。游戏内素材均为花溪原创图像，没有导入星露谷截图或游戏贴图。沙滩物件不绘制地名或人物头顶文字；碰撞、可行走路线和出口继续由地图数据控制。

追加对社区中心修复机制的参考：社区进度的可见反馈应直接落在场景建筑上，完成捐献后让玩家看见村庄发生改变。我们生成了原创的破损/修复会堂双态素材 `assets/art/runtime_generated/community_center_v1.png`，并接入捐献进度与存档。参考《星露谷物语》[社区中心资料](https://wiki.stardewvalley.net/Community_Center)。此处仅借鉴“任务完成改变地点状态”的反馈方式，没有复用原作画面或贴图。会堂新画面尚未重新生成游戏实机截图。

城镇使用现有建筑、喷泉与公告板素材，并在广场边缘布置树、长椅和路灯；这些物件都有相应实体阻挡格，不会占据主通路。

2026-09-24补看《星露谷物语》[官方媒体截图页](https://www.stardewvalley.net/media/)与[官方新闻资料页](https://www.stardewvalley.net/press/)中的场景图像入口。对本项目的转译重点是让海岸水线成为有轻微变化的场景边界，同时保留渔屋、潮池和栈台作为探索路线上的视觉停靠点。新增原创水岸泡沫/波光循环层：只绘制在水面与陆地交界处，不导入原作截图或贴图，不改变导航、碰撞和拾取数据；离开沙滩或隐藏沙滩地图时停止动画刷新。

### 2026-09-25：五区场景参考复查与补强顺序

本轮重新检索了[官方媒体截图页](https://www.stardewvalley.net/media/)、[官方 press kit](https://www.stardewvalley.net/press/)中的游戏画面入口，并查阅区域资料。区域资料进一步确认，场景辨识来自区域活动组合：海滩把海钓、潮汐拾取和渔屋/码头集中在岸线；森林区域用河流、池塘、树群和季节采集物组成穿行路线；矿区则以矿层资源和敌对遭遇形成深入探索的节奏。我们只借鉴“地标引导路线、路线承载活动、区域外观呼应玩法”的构图原则，不复用星露谷画面、地图或素材。

对照项目当前的五区窗口截图后，优先问题是场景组织而非装饰总量：

- **农场**：农田、住宅与养殖设施缺少清楚的庭院分区；让菜畦、鸡舍/围栏、出货与水边设施各自成组，并用一条清楚的步行路径连接。首屏应能读出“住家—耕作—照料—出货”的次序。
- **小镇**：建筑已经建立地标，但广场仍像未完成的空地。把中心铺装/喷泉作为聚集核心，商店、诊所、咖啡馆和居民住宅各自朝向可通行的主街；居民日程需要把人分布到广场与服务点，而不是让场景只靠建筑说明用途。
- **沙滩**：保持入口能看到海岸边界和渔屋，把潮池、贝壳/漂流物、长椅和码头依岸线串起来；空沙地保留作活动空间，拾取点成小簇分布，避免零散点位像装饰贴图。
- **郊外**：现有笔直土路和规则水池读起来像人工通道。下一版以弯曲溪流、桥、林缘和采集小径构成自然路网，在岔路放置可阅读路标；道路保持连续且不被装饰挤窄。
- **山洞**：已有暖色入口层、冷色中层、紫灰深层的色温区分和火把氛围。后续应把矿脉/碎石改为疏密不均的岩层群，留出看得懂的行走廊道、梯口和安全落脚区，而不是继续均匀增加矿块。

依据[星露谷海滩地点资料](https://wiki.stardewvalley.net/The_Beach)、[森林区域资料](https://wiki.stardewvalley.net/Cindersap_Forest)、[农场地图资料](https://wiki.stardewvalley.net/Farm_Maps)，场景补强下一轮先做**郊外与小镇构图小样**：郊外试弯曲溪岸和自然植被边界，小镇试广场地面层次、服务建筑朝街关系及居民停留点；先用当前地图数据验证路线和碰撞，再决定是否铺开到其余区域。该顺序针对截图中最明显的空地/规则布局问题，也避免再给五区同时堆一轮无关紧要的小物件。随后单独处理沙滩沿岸活动点分组与农场庭院分区。所有地点说明仍由固定路标阅读面板提供；禁止地面文字和人物头顶文字。

本轮按该顺序做了首个郊外/小镇小样：郊外直水槽改为分段轻微弯曲的溪流，并把对称散点树木重组成几组林缘；小镇广场通往主街、南巷的铺装范围扩大，增加低对比错缝石板层，让中心公共空间区别于土路。窗口复核后调低石板的底色和缝线强度，避免广场看起来像铺满规则网格的停车场。验收截图 `countryside.png`、`town-plaza.png` 由真实 Godot D3D12窗口生成；`regional_world_test.gd` 五区路线/碰撞共365项、0失败，包含溪流跨桥、广场南北/东西连接和居民路线。
