# 矿洞矿脉美术与玩法验收

三层洞穴原先都以一块灰色多边形表示矿石，再覆盖少数纯色小方块。当前 `ore_deposits_v1.svg` 使用八种独立的像素矿脉轮廓：铜矿呈暖橙色脉纹、铁矿呈冷青银色晶面、煤块近黑色、石英由淡紫晶簇突出，四种稀有宝石则分别以土黄、紫、冰蓝和火橙色晶体呈现。`homestead_scenery.gd` 根据 `MiningState.vein().material` 选择图格，受击裂痕仍按矿脉伤害显示；`game.gd` 复用图集作为矿物背包图标。

矿点仍由原挖掘系统控制：面对矿脉挥镐、消耗体力、击碎后拾取、镐子升级、矿层门槛、每日刷新、存档与工具材料均保持原闭环；新增地晶、紫水晶、冰泪与火水晶分别固定于不同深度矿层，进入资源背包，可出货、送礼和存档。

Godot 4.7.1 / Windows / D3D12 / RTX 3050实机检查：测试会检查八格图集尺寸、各层矿物覆盖，并实际使用镐子采集四种宝石、确认背包图标和售价、真实存档恢复及出货收入。画面：`mine-2.png`、`mine-3.png`。
