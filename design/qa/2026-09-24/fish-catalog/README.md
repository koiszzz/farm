# 鱼类图鉴与物种图标

钓鱼已有溪鱼、鲶鱼、夜鳗、沙丁鱼、比目鱼、红鲷、鱿鱼和金枪鱼八种鱼，过去背包一律复用溪鱼图标，图鉴中未发现物种也只有一行“尚未发现”。本次制作 128×64 透明原创像素图集，八种物种分别映射至 32×32 图格，并接入背包和旅行手册鱼类图鉴。

图鉴保留未发现鱼种的名称问号，但提供淡水/海水、适用季节、出没时段与天气线索；成功发现后再展示累计数量、出货价和体力恢复值。钓鱼规则、掉落概率、存档键与旧版溪鱼数量迁移不变。

Godot 4.7.1 / Windows / RTX 3050 / D3D12 实机截图：`guide.png`。`fishing_gameplay_test.gd` 44项、0失败，检查图集尺寸、八种各异且在界内的图格、真实钓获进入背包、图鉴条目覆盖和旧存档迁移。
