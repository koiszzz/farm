# 主角四向步态图集 v7 / 运行版 v4

基于现运行主角配色与形象生成，并按8×4格缩放、居中。原始像素现作为 `assets/art/runtime_generated/farmer_walk_v4.png` 运行；此处保留候选源与分析历史。

## 检查结果

- 图像尺寸1536×1024，可精确切成32格，每格192×256像素；垂直与水平网格边界的透明像素检查均为0。
- 四行最近相邻帧相似度分别为0.9336、0.9462、0.9196和0.9640。数值越高表示帧越相似；背向行走最接近的一对帧仍几乎重复。
- 原始帧中最低不透明点的Y跨度分别为10、22、34和40像素。运行时会用图格锚点归一化底部位置，但这些值也反映各行姿势的垂直构图差异。
- 第一次实机对照发现按整格高度缩放会让带透明边距的角色显得过小；`AvatarRenderer` 现按每帧裁切后的可见高度等比缩放，`avatar_rendering_test.gd` 验证四向32个姿势尺寸一致。归一后的实机对照见 `../avatar-walk-v4/live-cycle.png` 与 `live-run-cycle.png`。
- 最近帧相似度依旧最高为背向0.9640，仍需后续美术工作改善背向动作差异。本次接入是通过格边、体型和实机渲染门槛的迭代改进，不代表步态已完成主观试玩验收。

逐帧数据保存在 `frame-analysis.json`。当前步态循环仍须由更一致的角色尺寸、脚底基准和四向关键姿势重绘解决；增加源帧数量本身不能作为合格标准。
