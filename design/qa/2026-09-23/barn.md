# 牛棚、奶牛与奶酪机首版验证

`barn_gameplay_test.gd` 在 Godot 4.7.1 下执行 56 项、0 失败，并使用独立临时存档。真实 Windows D3D12、RTX3050 截图为 `barn/barn.png`。

覆盖范围：

- 牛棚建造缺料零扣除，以及 650 金币、木材 20、石料 12 的精确消费。
- 施工位置不覆盖池塘、树木、建筑、耕地或既有土路，并与既有鸡舍围栏不重叠。
- 两头奶牛容量、满舍拒绝、干草共享存储、每日喂食与防重复。
- 小牛当日不可挤奶；前一晚吃饱的成年奶牛次日可挤一桶奶；同日不可重复挤奶；漏喂次日无奶。
- 牛棚与围栏玩家碰撞、开放大门、农场伙伴避障、奶牛在围栏内漫步。
- 靠近户外奶牛按 F：有奶时挤奶进背包，无奶时抚摸；爱心反馈。
- 牛棚门口真实上下文交互打开面板，逐只喂食/抚摸/挤奶，干草不足原子失败。
- 牛奶进背包后可食用恢复 22 体力，或通过出货箱以 125 金币出售。
- 耕种 3 级解锁奶酪机（木材 10、石料 6、铜矿 3），安装后消耗一桶牛奶隔夜制成价值 230 金币、恢复 40 体力的手工奶酪；忙碌机器禁止镐子拆除，成品必须交互收取后才进入背包，可食用或出货。
- 牛棚、奶牛身份/年龄/亲密度/挤奶记录、干草、牛奶与奶酪全部进入存档；旧档缺少 barn 字段时保持兼容；重复奶牛 ID 与无棚奶牛拒绝读取。

Windows D3D12/RTX3050 真实截图已检查：牛棚与鸡舍在 1.5 倍镜头下形态可区分，奶牛与鸡为无文字程序化小型动画角色，饲料槽在各自围栏内，地面与人物头顶没有新增文字。

限制：当前只有鸡和奶牛，没有羊、羊毛、动物疾病、孵化、牧草种植或自动喂食器；牛棚与奶牛为程序化原创原型图形，后续仍需统一像素图集与更细的行走动画。
