## 操作

- WASD / 方向键移动，Shift 跑步。
- 1–6、滚轮或底部工具栏切换工具；左键 / E 使用。
- 右键 / F 进入门口交互、拾取、和居民交谈或抚摸麦麦。
- P 查看麦麦；靠近后可喂一份野莓，或让它回家等待。
- I 打开背包，G 给附近居民送礼，R 查看居民，M 地图，Tab 日历。
- 水井补水；出货箱出售作物及拾取物；作物委托在居民对话中交付。
