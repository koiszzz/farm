# 区域钓鱼与图鉴验证

Godot 4.7.1，Windows/D3D12，RTX3050。`fishing_gameplay_test.gd` 25项、0失败；`guide.png`为真实渲染截图。

覆盖淡水/海水、季节、晴雨、昼夜鱼池；同条件连续抛竿在候选鱼中轮换。游戏层测试实际海滩水格抛竿、动作接触扣体力、物种等待时间、提竿窗口、错过无奖励、独立背包条目、食用恢复、出货箱按物种价格结算及图鉴发现。真实临时存档验证鱼获与发现记录，测试结束清理自身文件。

旧`fish_count`仍作为聚合兼容属性；无新钓鱼数据的旧档会把数量迁为溪鱼。旧`food:fish`快捷栏继续指向溪鱼，不会因新增物种失效。

当前是限时提竿玩法，物种共用图标。尚需鱼行为式小游戏、品质/尺寸、鱼竿升级和独立美术，不能把本轮验证解释为最终钓鱼系统完成。
