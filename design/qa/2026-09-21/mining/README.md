# 采矿与工具成长验证

Godot 4.7.1，Windows/D3D12，RTX3050。`mining_gameplay_test.gd` 44项、0失败，截图 `mine.png` 已查看。断言覆盖实际游戏动作接触结算、升级交易、层级入口、返回、库存、真实文件保存/读取、1点体力使用铜水壶和次日资源刷新。

测试用独立临时存档，结束清理自己的主档及备份。升级支付验证阶段设置1000金以隔离作物经济，这不构成自然多日经营平衡证据。

操作：镐子默认放在新游戏快捷栏7；旧档中新增镐子进入背包，可拖入快捷栏。面对矿石按E敲击；普通镐需两次敲碎第一层矿石。带5铜矿、2煤和150金到种子铺工匠柜台升级后，第一层北侧梯子可前往二层。铁级需要5铁矿、3煤和400金，可进入三层取得石英。梯子按F使用。出货箱保留升级矿材。

当前三层使用基础岩室布局和程序绘制矿石，视觉、探索变化和长期收益仍需改善，未验收为最终游戏质量。
