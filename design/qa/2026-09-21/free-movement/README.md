# 自由移动首轮验证

实现：连续二维运动，128世界像素/秒、Shift乘1.65，斜向归一化；碰撞沿表面滑动，无整格完成等待；镜头1.5倍。

`movement_input_test.gd` 使用实际InputEventKey，验证松键停在格子之间、下一tick反向、斜走等速、对向按键抵消、贴墙滑动、不穿墙、静止脚步不推进。`world_travel_test.gd` 通过实际键盘状态和物理位移走遍户外连接及四座建筑出入；工具测试验证移动中操作在当前位置开始。

`latest.json` 和 `walk-after.png` 来自真实Windows/D3D12/RTX3050运行。48格路径、720渲染帧完成。该回放每个渲染帧手动执行一次固定移动步长，用来测量路径呈现开销；不能充当生产物理频率下的完整帧率测量。P95=24.326ms、P99=25.678ms、最大78.347ms，尚未达成计划性能目标。首帧尖峰和碰撞流送仍需优化。

截图确认世界放大、主角可读性提高。画面仍存在地面文字和密集草纹、HUD较拥挤；这些不是最终美术验收状态。头顶/地面无字与实体路标安排在下一阶段，主角步态图集尚未重绘。
