# 镇区早间居民路线复核

## 发现

早间排班会让10位居民同时到镇上，但镇区地图原先只给花店主、杂货店主和渔夫编了路线。剩下7人按居民表下标轮流复用这3条回路，多个NPC会从同一个格子出发，并沿着同一段路线重叠巡逻。

## 修改

`design/maps/outdoor_navigation_v1.json` 现在为10位居民各提供一条镇区巡逻路线，分别经过杂货店街、喷泉广场、咖啡馆侧街、桥边和会堂小路。路线端点通过地图寻路连接；导航和交互仍由原地图格数据控制。早间出生站位按实际运行结果测得的最小间距为71.6世界像素（2.24格）。

## 验证

- Windows / Godot 4.7.1 / NVIDIA RTX 3050 / D3D12实拍：`town-morning-patrols.png`。
- `resident_schedule_test.gd`：234项、0失败；验证10条路线都完整可行走，早间NPC最近距离不低于64像素，并回归日程边界、郊区/海滩巡逻和雨天室内安排。
- `regional_world_test.gd`：334项、0失败；`world_travel_test.gd`：0失败；`game_smoke_test.gd`通过。

截图仅显示以玩家为中心的一个镇区视野，未展示离屏居民。不同季节、节日和一天内居民经过拥挤路口时的避让行为仍需单独试玩验证。
